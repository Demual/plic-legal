# Documentos legales de Plic

Política de privacidad de la aplicación **Plic**, un recordatorio para beber
agua para Android.

Este repositorio existe solo para servir esos documentos por HTTPS con una URL
pública y estable, que es requisito de Google Play, de Health Connect y del
mensaje de consentimiento de AdMob. **No contiene el código de la aplicación.**

Las traducciones (14/10/2026, decisión de Javier) dicen que, si hay diferencias,
prevalece la versión en español.

Se publica con GitHub Pages desde la rama `main`: `https://demual.github.io/plic-legal/`
(la portada lleva a la versión del idioma del navegador, o a la inglesa; con
`index.html#todos`, el enlace «Otros idiomas» del pie de cada política, enseña la lista).
El historial de commits sirve además como registro de qué decía la política en cada
momento.

La URL base se pasa a la app en `local.properties` (`PRIVACY_URL=...`); por
defecto es la de arriba.
